#LIVESTOCK MANAGEMENT DATABASE SYSTEM

PROJECT OVERVIEW:
This project focuses on designing a relational database for organizing livestock records and making farm-related information easier to retrieve, monitor, and analyze.

PROBLEM:
1. Keeping livestock information in scattered files or manual records makes it difficult to retrieve individual animal records
2. Monitoring farm activities and generating useful summaries becomes difficult.

OBJECTIVE: 
1. Develop a structured database that stores livestock information 
2. Supports efficient record retrieval through SQL queries

WHAT I DID:
1. Designed and populated a database with livestock records and related information based on the project’s requirements. 
2. Created SQL queries to retrieve specific records, filter information, summarize data, and answer relevant questions about the stored records. I also used sample data to test the database structure and query results.

TOOLS: SQL, MYSQL and MySQL Workbench.

RESULT:
The database provides an organized approach to storing and retrieving livestock information, demonstrating how relational databases and SQL queries can support record management and reporting.

Key Features:
1. Relational database structure.
2. ER blueprint
3. Livestock record storage.
4. Data insertion and retrieval.
5. SQL queries for filtering and searching records.
6. Summary queries and data aggregation.
7. Database testing using sample records.
